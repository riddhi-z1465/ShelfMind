System Architecture

How ShelfMind Works

End-to-end dual-pipeline operational model demonstrating physical RFID circulation and concurrent digital lending arbitration.

Physical Book Circulation Pipeline
ISO 15693 / UHF EAS
NODE 01
Student
Patron taps institutional smartcard at workstation.
NODE 02
Search Book
Patron browses catalog via Title, Author, ISBN or Stack location.
NODE 03
RFID Issue
Antenna scans tag, sets loan period (14 days), disarms EAS bit.
NODE 04
Library Database
Central ledger records active loan and patron account association.
NODE 05
RFID Gate
Exit portal queries EAS byte: disarmed passes, armed triggers alarm.
NODE 06
Return
Smart chute checks condition, rearms EAS, fulfills hold queue.
Controlled Digital Lending (CDL) Pipeline
5-Slot Concurrent Mutex
NODE 01
E-book
Patron requests access to licensed academic digital monograph.
NODE 02
Licence Check
Concurrency engine queries 5-licence pool capacity (N < 5).
NODE 03
Licence Allocation
Atomic test-and-set mutex assigns token, rejecting concurrent races.
NODE 04
Digital Session
Encrypted e-reader opens with live patron interaction watchdog.
NODE 05
20-Min Idle Timeout
Background timer detects inactivity without patron keepalive.
NODE 06
Licence Released
Token returns to institutional pool immediately for waiting scholars.
