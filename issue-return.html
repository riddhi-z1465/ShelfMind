Automated Return Ledger Pipeline

Fine Calculation Service
Independent microservice daemon
Online

When an RFID tag enters the return chute:

  1. Transponder tag is matched with active circulation loans table.
  2. Timestamp differential is evaluated against the 14-day policy.
  3. If overdue, a fine assessment is logged to the Student Bursar Ledger.
  4. The transponder Electronic Article Surveillance (EAS) security bit is toggled back to ARMED.
  5. Stack sorting conveyor indexes the book for reshelving.
